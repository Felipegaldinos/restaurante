# Sabor & Alma

Site de restaurante em React com cardápio, galeria, eventos e reservas.

## Recursos

Componentes dedicados às seções, formulário de reserva e widget de chat.

## Tecnologias

React, JavaScript e Vite. Consulte package.json para as dependências e versões declaradas.

## Executar localmente

Use Node.js e npm compatíveis com as dependências declaradas:

```sh
git clone https://github.com/Felipegaldinos/restaurante.git
cd restaurante
npm install
npm run dev
```

Abra o endereço exibido no terminal. `npm run build` gera a versão de produção. `npm run preview` permite visualizar esse build.

## Onde começar no código

- `src/App.jsx` — ponto de entrada para entender o projeto.

## Estado atual

O formulário em Reservations.jsx valida dados, mostra sucesso e limpa os campos, sem transmitir uma solicitação. Não há confirmação real de reserva nesse manipulador.
